# Python Programming Internship - Task 2

## Student Record Management System

A menu-driven Python application developed as part of Task 2 of the Python Programming Internship. The project demonstrates Python data structures, string handling, file handling, exception handling, Object-Oriented Programming (OOP), and CRUD operations.

## Features

- Add student records
- View all student records
- Search student by roll number
- Update student records
- Delete student records
- Store student data in CSV format
- Input validation
- Exception handling
- Object-oriented design
- Menu-driven command-line interface

## Technologies Used

- Python 3.12+
- Visual Studio Code
- CSV file handling
- Git and GitHub
